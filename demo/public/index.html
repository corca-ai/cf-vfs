Edit a file while the shell does

Open a file, then change it from the terminal — sed -i lands here as an edit instead of overwriting what you typed.

Everyone visiting from the same country shares one workspace here, so what you write is what the next person finds — and can change. It holds fifty kilobytes; when it is full, deleting something makes room. A public whiteboard, not your own.

  • A sandbox for an agent, without a container

    Files and a shell inside one Durable Object. Nothing to build, boot, or clean up — and no machine underneath for anything to escape onto.

  • Ready the moment you name one

    The filesystem is rows in SQLite, so there is no image to pull and nothing kept warm between uses. A workspace starts in milliseconds and costs nothing while idle.

  • The commands behave like the ones they are named after

    Seventy-five of them — grep, sed, jq, find — answering to recordings from real GNU, Bash, and jq. Where this differs on purpose it says so rather than guessing.

  • A runaway command stops itself

    Every run carries ceilings on time, output, memory in flight, and how much it may change. Try while true; do :; done — it ends on its own instead of taking the object with it.
